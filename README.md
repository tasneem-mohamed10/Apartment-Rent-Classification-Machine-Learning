# Apartment Rent Classification - Machine Learning

## Project Overview

This project is a Machine Learning classification project that predicts apartment rent levels using different classification algorithms.

## Machine Learning Algorithms
- K-Nearest Neighbors (KNN)
- Decision Tree
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
## Project Workflow
1. Data Loading
2. Data Preprocessing
3. Exploratory Data Analysis
4. Data Visualization
5. Model Training
6. Model Prediction
7. Model Evaluation
## Dataset
The project uses an apartment rent dataset for classifying rent levels.
